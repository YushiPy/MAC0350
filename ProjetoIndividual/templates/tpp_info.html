The Touring Polygons Problem

The Touring Polygons Problem (TPP) is a computational problem that involves finding the shortest path that starts at s, visits a sequence of polygons P_1, ..., P_k in a specified order, and ends at t. The path must intersect each polygon in the sequence at least once.

This problem is a specific case of the more general Traveling Salesman Problem with Neighborhoods (TSPN), where the "neighborhoods" are represented by the polygons and the visit order is fixed. The TPP can be shown to be NP-hard if the polygons are allowed to be arbitrary, however, when restricted to convex polygons, the problem can be solved in polynomial time.

This problem has applications in various fields such as robotics, where a robot may need to navigate through a series of areas (represented by polygons) in a specific order, and in logistics, where a delivery route must be planned to visit certain locations (represented by polygons) in a specific sequence.

This visualizer allows users to move the points s and t, as well as the vertices of the polygons, to see how the shortest path changes in real-time. It provides an interactive way to understand the TPP and its properties.
